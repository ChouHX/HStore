# 2026-10-26

## 取件改为独立公开页（参考 Redeem）

### 问题
原实现把取件放在 `/account/pickup`，套在 `AccountLayout` 登录守卫里，未登录直接跳登录页。
Redeem 的取件页（`/mail` → `MailConsole`）是独立页面、凭卡密即可访问，形态不同。

### 前端
- 新增 `src/pages/PickupPage.tsx`：全屏独立页（自己的 header：Logo + 返回商城 + 登录/个人中心），
  未登录只有输入框；登录后额外展示「我的邮箱」列表。
- 新增 `components/MailboxPanel.tsx`：把原 `MailboxDrawer` 的列表/正文逻辑抽出，可内嵌；
  `MailboxDrawer.tsx` 降级为 `Drawer + MailboxPanel` 的薄壳（订单详情仍用它）。
- 路由：`/pickup` 公开；`/account/pickup` → `<Navigate to="/pickup" replace />` 兼容旧链接。
- 删除 `components/account/PickupSection.tsx`；`AccountLayout` NAV 与 `StoreHeader` 的取件入口都改指 `/pickup`。
- `StoreHeader` 的「取件」按钮移出 `user ?` 分支，未登录也显示（移动端只显示图标）。

### 后端
- `service/mailbox.go`：`resolveOrder` 增加匿名分支（`uid <= 0`）。
  **匿名只允许兑换码，不允许订单号**（订单号来自上游、可枚举；兑换码 16 位随机，熵足够）。
  匿名时跳过 `UsedBy` / `UserUID` 归属校验，登录时校验不变。
- `httpapi/handlers_order.go`：新增 `mailboxActor()`，`/api/mailbox/list`、`/api/mailbox/detail`
  改为可选登录；`/api/mailbox/cards` 仍需登录（「我的邮箱」）。
- 新增 `httpapi/ratelimit.go`：匿名取件按 IP 限流，1 分钟 12 次，超出 429；
  `clientIP()` 依次取 `CF-Connecting-IP` / `X-Real-IP` / `X-Forwarded-For` / `RemoteAddr`。

### 顺手加固
`store/orders.go` 的 `GetOrder` / `listCards` 给可空列加 `COALESCE`
（`result`/`platform`/`sale_money`/`cost_money`/`source`/`settled`/`card_pwd`/`cancel_request`）。
这些列是后期 `ALTER TABLE` 加的，老数据为 NULL 时 `Scan` 失败会让 `GetOrder` 直接返回 nil，
表现为「订单不存在」——取件、订单详情一起挂。

### 验证（临时库 + 单文件二进制，PORT=3056）
- 匿名 + 兑换码 → 通过鉴权，走到 OAuth（假 token 被微软拒绝，符合预期）
- 匿名 + 订单号 → `未登录只能用兑换码取件，订单号请登录后使用`
- 匿名 + 不存在的码 → `兑换码不存在`
- 匿名 `/api/mailbox/cards` → `请先登录`
- demo 登录 + 他人订单 → `无权查看该订单`；他人兑换码 → `该兑换码不是你的，无法取件`
- 连续 14 次匿名请求：第 1–12 次 400，第 13–14 次 **429**（限流生效）
- `/pickup`、`/account/pickup` 均 200；`tsc --noEmit` / `go build` / `go vet` 通过
